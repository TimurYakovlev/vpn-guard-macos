# VPN Guard — Windows и macOS

Открытая защита рабочей сессии для Claude, ChatGPT/Codex и нативных CLI.
После запуска системы сторож ждёт VPN. Подключение начинает защищённую
сессию; обрыв сохраняет её. Перед ручным отключением VPN завершите сессию
кнопкой или командой `end`, чтобы вернуть обычный интернет приложениям.

**Preview 0.2.0. Это не гарантия отсутствия утечек.** В режиме ожидания и после
завершения сессии приложения могут выходить напрямую. Механизмы защиты
Windows и macOS различаются; условия и ограничения приведены в инструкциях.

| | Windows x64 | macOS |
|---|---|---|
| Механизм | WFP-фильтры прямых IPv4/IPv6-соединений выбранных EXE | Приостановка/возобновление выбранных процессов |
| Поддерживаемый VPN | Amnezia XRay/VLESS, TUN `tun2` | Полный `utunN`, подтверждённые стабильные внешние IP |
| При обрыве активной сессии | Фильтры сохраняются и запрещают прямой выход | Сторож обнаруживает проблему и посылает `SIGSTOP`; до этого возможна утечка |
| Права | Администратор при установке; начало/конец сессии без UAC | Обычный пользователь, без `sudo` |
| Установка | `windows/Install.cmd` | `sh control.sh install` из корня |
| Инструкция | [Windows](windows/README.txt) | [macOS](docs/macos.md) |

## Скачать и запустить

[Релизы и архивы по платформам](https://github.com/TimurYakovlev/vpn-guard-macos/releases).
История изменений: [CHANGELOG.md](CHANGELOG.md). Название репозитория сохранено
ради прежних ссылок; Windows-исходники находятся отдельно в `windows/`.

**Windows:** распакуйте Windows-архив и запустите `Install.cmd`. В ZIP исходников
GitHub эта команда находится в папке `windows`. Установщик соберёт DLL штатным
компилятором .NET Framework, запросит администратора, создаст системного сторожа,
значок в трее и ярлык. Нужны Windows 10/11 x64 и Windows PowerShell 5.1.
Не перезаписывает другую/неизвестную существующую установку.

**macOS:** нужны Python 3.10+, подключённый полный VPN и его штатный kill switch.
В корне распакованного Mac-архива или исходников выполните:

```sh
sh control.sh install
```

Настройщик требует явного подтверждения доверенного IP и путей приложений.
Прежние `install.command`, `status.command`, `end.command`, `uninstall.command`
и `control.sh` остаются в корне; подробности — в [инструкции macOS](docs/macos.md).

## Что покрыто

Защита относится к найденным поддерживаемым приложениям в активной рабочей
сессии. VPN сам по себе не заменяется и не настраивается. Код не содержит
профилей VPN, ключей, IP сервера, личных путей или состояния компьютера автора.

Общие DNS-службы, выход локальных прокси, виртуальные машины и новые пути
исполняемых файлов не дают полной изоляции. Windows обнаруживает новые пути
опросом; macOS приостанавливает процессы после обнаружения проблемы. Подробные
границы охвата и восстановление описаны отдельно для каждой платформы.
Проверяйте установку на своём устройстве после сохранения работы.

## Проверки разработки

```sh
python3 -m unittest discover -s tests -v
```

Windows PowerShell, без установки и изменения сети:

```powershell
.\windows\Build.ps1
.\windows\SelfTest.ps1
```

CI использует Windows, Apple Silicon и Intel Mac. Mac-интеграционные тесты
используют изолированный HOME и собственный тестовый процесс; они не проверяют
реальные приложения или отсутствие утечки при обрыве вашего VPN.
